# Elvis Lustosa Barbearia + animação por scroll

Estrutura obrigatória:
- index.html
- sequence.css
- sequence.js
- frames/frame-0001.jpg ... frames/frame-0117.jpg

Coloque os 117 JPGs dentro da pasta `frames`, mantendo exatamente esses nomes. Depois, suba a pasta inteira para sua hospedagem com HTTPS.

A animação usa Canvas, pré-carrega os frames, preserva a proporção, acompanha o scroll e respeita `prefers-reduced-motion`.

Antes de publicar: troque o WhatsApp fictício, confirme endereço/horários e substitua os depoimentos de demonstração por avaliações reais.
